# Code Vipassana 課題発掘シート — Civic Lens 情報公開請求サポートエージェント

## ワークショップ：Code Vipassana（AIエージェント構築メソッド論）
Code Vipassanaは、内観（自己観察）を経て、AIエージェントを体系的に設計するメソッド論。
- **Vipassana（ヴィパッサナー）**: 自身・顧客の行動・感情・思考を観察し、真のペインを発見する瞑想法
- **Code Vipassana**: 発見したペインを、AIエージェントで自動化するプロセス

---

## 1. Solution Name（ソリューション名）

### **Civic Lens（シビック・レンズ）**
- 市民 + Lens（視点）= 市民の視点ツール
- 行政文書を「市民の立場から」読み解くエージェント
- 別名候補: CivicBeacon、DisclosureDesk、PublicRecordAgent

---

## 2. Domain（ドメイン）

### **Public Administration × Civic Tech × Legal Aid**
- 公的制度（行政法・情報公開制度）
- シビックテック（市民と行政の距離を縮める技術）
- リーガルエイド（法的支援へのアクセス向上）

---

## 3. Challenge（解決したい課題）

### **行政の不誠実さ**が、市民の権利行使を阻害している：
1. **「行政文書の不存在」を盾にした逃げ**
   - 安城市は令和7年8月28日付けで「誤り」として原処分を取り消したが、棄却裁決の方針を伝達
2. **形式的に応じるが、実質的に隠す対応**
   - 「黒塗り」地獄
   - 紋切り型の不開示理由（条例8条2号「法人情報」、6号「事務執行影響」）
3. **裁決の遅延による事実上の救済妨害**
   - 審査請求 → 答申まで6ヶ月〜2年
   - 事件の風化 → 市民の関心が冷める

### **市民の諦め**が、制度の空洞化を招いている：
1. **「何を請求していいか」がわからない**
2. **60日ルールの意味がわからない**
3. **審査請求のフローがブラックボックス化**
4. **弁護士費用のハードルが10万円〜**

---

## 4. Specific Issue to Address（具体的に取り組む課題）

### **Issue #1: 開示請求書作成の心理的・手続的障壁**
- 問題：市民が「自分の知りたい情報をどう請求書に書くか」がわからない
- エージェント解決策：対話型ヒアリング → 自動生成

### **Issue #2: 不開示決定への反論ロジック不在**
- 問題：不開示理由が抽象的で、市民が反論できない
- エージェント解決策：不開示事由の条文適合性を自動チェック → 反論ロジック生成

### **Issue #3: 判例・先例アクセスの欠如**
- 問題：他市の開示例・判例が散在し、市民が引けない
- エージェント解決策：Parallel Web Searchで自動調査

### **Issue #4: 期限管理の属人化**
- 問題：60日ルール、延長通知、審査請求期限の管理が個人の記憶に依存
- エージェント解決策：Cloud Scheduler + Grafana で期限ダッシュボード化

---

## 5. Impact（もたらす影響）

### **直接的なインパクト**
- **市民1人あたりの時間削減**：開示請求書の作成 **3時間 → 10分**
- **成功率向上**：反論ロジック生成により、不開示決定からの救済率 **+15-20%**
- **弁護士コスト削減**：着手金10万円 → AIエージェント利用で **0円**

### **構造的なインパクト**
- **行政の透明性向上**：市民が請求しやすくなる → 行政の説明責任が問われる
- **報道の自由強化**：記者・フリージャーナリストの調査報道が深化
- **地方自治の民主化**：市民と行政の情報非対称が解消

### **社会的インパクト（Potential Impact スコア：高）**
- 「司法アクセス」の憲法上の権利を、AIエージェントで実体化
- オープンソース化により、全国の自治体・NPOが即座に導入可能

---

## 6. Target Users（想定ユーザー）

### **Primary: 個人市民**
- 30-60歳、政治・行政への問題意識あり
- 弁護士費用を払えない層
- 行政手続に不慣れな層
- ペイン：「権利として請求したいが、方法がわからない」

### **Secondary: 記者・調査報道**
- 地元新聞記者、フリー記者
- 報道ネタの深掘り
- ペイン：「市役所とのパイプが弱い」「時間がない」

### **Tertiary: 行政書士・NPO**
- クライアントワークの効率化
- 公益活動
- ペイン：「条例・様式の地域差が大きい」「期限管理が属人的」
