# ドメインモデル — 開示請求対象機関の網羅定義

## 開示請求対象機関（日本国内）

### 1. 執行機関（行政）
#### 国レベル
- 内閣総理大臣
- 各省大臣（法務、財務、経産、国交、厚労、文科、防衛、外務、農林、環境、総務、デジ庁）
- 会計検査院
- 人事院
- 各省庁の出先機関（地方支分部局）

#### 都道府県レベル
- 都道府県知事
- 都道府県教育委員会
- 都道府県公安委員会 / 警察本部長
- 都道府県選挙管理委員会
- 各都道府県知事の所轄機関（県立病院、企業局 等）

#### 市町村レベル
- 市町村長
- 市町村教育委員会
- 市町村選挙管理委員会
- 市町村消防長 等

### 2. 議事機関（議会）
- 衆議院 / 参議院
- 都道府県議会
- 市町村議会
  - ※議会独自の「議会情報公開条例」に基づく

### 3. 独立行政法人・特殊法人
- 独立行政法人（101法人）
- 特殊法人（13法人）
- 認可法人
- 国立大学法人

### 4. 公的企業体
- 日本銀行
- 日本赤十字社
- NHK（放送法に基づく）

### 5. 司法関連
- 裁判所（最高裁判所、各高等裁判所、地方裁判所、家庭裁判所、簡易裁判所）
- 検察庁（法務省所管だが特殊運用）

## 条例の特殊性 — 各レベルで別個の条例

| 対象 | 条例名（例） | 不開示事由 | 審査請求先 |
|---|---|---|---|
| 都道府県知事 | ○○県情報公開条例 | 個人情報、法人情報、事務執行影響 等 | ○○県情報公開審査会 |
| 市町村長 | ○○市情報公開条例 | 同上 | ○○市情報公開審査会 |
| 都道府県議会 | ○○県議会情報公開条例 | 議員活動、議会運営 等 | ○○県議会情報公開審査会 |
| 国 | 行政機関の保有する情報の公開に関する法律 | 改正後5類型+独法等 | 情報公開・個人情報保護審査会 |
| 警察本部 | 警察本部長情報公開 | 捜査情報、犯人識別 等 | 国家公安委員会 |

## 実装時の網羅戦略

### Phase 1（MVP — 44時間で実装）
- **対象機関**: 都道府県知事 + 市町村長 + 市町村議会 + 都道府県議会 = 4種類
- **対象自治体**: 愛知県（あなたの本拠地）+ 東京都 = 2エリア
- **対応形式**: 開示請求書 + 審査請求書 + 相談フォーム

### Phase 2（余裕があれば）
- 国レベル（府省別フォーマット）
- 警察本部特殊対応
- 独立行政法人

## 差別化ポイント

既存ツール（例: OpenGov, Transparency International ツール）は：
- 1つの条例にしか対応しない
- フォーム自動生成が主
- 審査請求の段階支援がない

**Civic Lens の差別化**:
- **複数対象機関・複数条例**を一つのツールで対応
- **審査請求まで含めた全フロー支援**
- **判例・他市事例の自動調査機能**（Parallel Web Search）
- **Gemini エージェントによる対話型ナビ**
