## 💡 ハッカソン実装アイデア（5時間で形になるもの）

### 案X：「市民の代理人AIエージェント — Civic Lens」（推奨）

**全スポンサー使用**

```
[市民] YouCam APIで感情（怒り）を検知
   ↓
[市民の怒りを入力] 駅すぱあとAPIで最寄り役所までの経路案内
   ↓
[Vertex AI Agent Engine (Gemini)]
   - 感情解析
   - 条例検索（GMI Cloudの高速推論）
   - 開示請求書生成
   - 期限管理
   ↓
[出力] 市民向けの法的アクション提案 + アクセス案内
```

**コア機能**：
1. YouCam API → 市民の怒りレベル測定
2. Gemini → 法的アクションへの変換
3. 駅すぱあと → 役所までの経路
4. GMI Cloud → マルチモーダル推論

**デモシナリオ**：
- カメラで市民の顔を撮影 → 怒り表情を検出
- 「海外視察費用の公開請求したい」と音声入力
- エージェントが条例・期限・必要書類を自動生成
- 駅すぱあとで「市役所までの最短経路」を表示
- 提出用のPDF自動生成

## 🛡️ 法的留意点（重要）

### 弁護士法72条（非弁行為）の回避
- AIは「**法的助言**」ではなく「**情報提供・書式作成支援**」に限定
- 最終判断はユーザーが行う（Human-in-the-loop）
- Legal AI株式会社がこのアプローチで法的クリア

### ハッカソン規約遵守
- 全スポンサーAPIを実際にコードで呼び出す
- Gemini のみを使用（OpenAI等他のLLMは不可）
- READMEにパートナー技術の呼び出し箇所を明示
