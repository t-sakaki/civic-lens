# 課題発掘シート — Civic Lens

## テーマ：「情報公開請求を取り巻く"怒り"と"不誠実"を、市民の手で解決する」

---

## 1. 自身の困りごと（ペいくんの実体験ベース）

### 1.1 行政の不誠実への怒り
- **「不存在」を盾にした逃げ**
  - 安城市は令和7年8月28日付けで「誤り」として原処分を取り消したが、棄却裁決の方針を伝達
  - 形式的に「不存在」と回答し、実質的に責任回避する手法が横行
- **抽象的・紋切り型の不開示理由**
  - 「法人その他団体の権利利益を害するおそれがある」（条例8条2号）
  - 「事務の公正かつ円滑な執行に支障が生じるおそれがある」（同6号）
  - → 具体的な理由が記載されず、争えない
- **形式的に応じるが実体は隠す対応**
  - 部分開示で「黒塗り」地獄
  - 開示文書のコピーに上質紙コピー料徴収

### 1.2 市民の孤立・諦め
- **「何を請求していいかわからない」**
  - 自治体のHPに開示請求制度の説明はあるが、利用者は年間数件程度
  - 行政手続に不慣れな市民は入口で挫折
- **「60日ルール」の意味がわからない**
  - 開示決定等の期間（処分庁による15日延長可、実務上60日待ちが常態化）
- **「不開示だったらどうすればいいか」がわからない**
  - 審査請求 → 諮問 → 答申 → 裁決 というフローがブラックボックス
- **弁護士費用のハードル**
  - 着手金10万円〜、市民には払えない
  - 法テラス（民事法律扶助）は償還原則で「後払い」の恐怖

### 1.3 制度の構造的問題
- **議会と長の不透明な関係**
  - 市議会の議会情報公開は市長側より更に遅れている自治体が多い
  - 「議会に問い合わせてください」とたらい回し
- **裁決の遅延**
  - 審査請求 → 答申まで6ヶ月〜2年
  - 事件の風化 → 市民の関心が冷める → 事実上の「勝利」だが社会的インパクトなし
- **判例・先例の散在**
  - 最高裁判例、各自治体の答申が個別PDFで点在
  - 「類似事例」が市民には引けない

## 2. 想定ターゲット像（共感する"怒り"を持つ人たち）

### 2.1 一次ターゲット：個人市民
- **属性**: 30-60歳、会社に勤める一般市民、政治・行政への問題意識あり
- **動機**: 「税金を使った行政の決定の根拠を知りたい」「自分の権利として請求したい」
- **ペイン**: 「何を請求していいかわからない」「拒否されたらどうしよう」「時間がない」

### 2.2 二次ターゲット：記者・調査報道
- **属性**: 地元新聞記者、フリー記者、報道番組ディレクター
- **動機**: 報道ネタの深掘り、公共事業の妥当性検証
- **ペイン**: 「市役所とのパイプが弱い」「開示請求を出す時間がない」「不開示の分析に時間がかかる」

### 2.3 三次ターゲット：行政書士・NPO
- **属性**: 行政書士、公益活動家、議会モニター
- **動機**: クライアントワークの効率化、社会的活動
- **ペイン**: 「条例・様式の地域差が大きい」「期限管理が属人的」

## 3. 解決したいペイン（優先順位）

### P0（最優先 — MVP必須）
1. **「何を請求していいか」が言語化できない**市民の支援
2. **開示請求書・審査請求書の自動生成**（条例別・機関別）
3. **期限管理**（60日ルール、延長通知の追跡）

### P1（高優先 — 差別化要素）
4. **不開示決定への反論ロジック生成**（不開示事由の条文適合性チェック）
5. **判例・答申の自動検索**（Parallel Web Search）

### P2（中期 — 余裕があれば）
7. **多言語対応**（外国人住民、在日外国報道機関）
8. **陳情・監査請求への展開**（審査請求以外の対抗手段）
9. **議会情報公開への対応**（市長側と別系統の条例）

## 5. 差別化ストーリー（審査員向け）

### 5.1 なぜ「Civic Lens」が必要か
- 日本の情報公開請求件数は年間約30万件（2024年度）
- しかし利用者は「行政手続きに慣れた層」に偏在
- 行政手続に不慣れな市民・記者が「諦める」構造的問題

### 5.2 ペいくんの実体験が「説得力」を担保
- 現役弁護士による実案件ベース
- 不存在決定の審査請求 → 取消し → 再度の不開示決定、という"行政のずるさ"を熟知
- 単なる「便利ツール」ではなく「市民の武器」として設計

### 5.3 「社会実装のリアル」
- 完成後、全国の自治体にプレスリリース
- 法テラス・行政書士会への展開
- 記者クラブへの無料提供
