# Civic Lens — Zenn Agentic AI ミニハッカソン

## 🎯 コアメッセージ

**「市民の怒りを情報公開に変換するエージェント」**

市民の「行政への怒り・不信・諦め」を、法的アクション（情報公開請求・審査請求）に自動変換する。

Civic Lens というシンプルなメッセージは、英語圏の審査員にも一発で通じる。

## 📊 ピッチ用サマリ（1分）

### 課題
- 年間30万件以上の情報公開請求があるが、**90%の市民が制度を使いこなせない**
- 「何を請求していいかわからない」「不開示だったら…」→ 弁護士10万円は払えない
- 行政の不誠実（不存在盾、紋切り型不開示理由）が市民の権利行使を阻害

### 解決策
**Civic Lens** — 4つのAPIを統合した本人支援型エージェント
1. 怒り表情を検知（YouCam API）
2. 条例を自動マッチング（Gemini + GMI Cloud）
3. 開示請求書・審査請求書を自動生成
4. 市役所までの経路案内（駅すぱあとAPI）

### 差別化
- **Civic Lens**: 韻を踏んだ記憶に残るネーミング
- **弁護士法72条遵守**: AIは法的助言ではなく情報提供・書式作成支援
- **Legal AI**（本人訴訟AI）の情報公開版
- **9機関対応**: 5自治体 + 4警察本部（誤認逮捕検証、警察官処分など権力監視の文脈も）

### インパクト
- 弁護士コスト0円 →市民の司法アクセス実現
- 行政の透明性向上
- 調査報道の支援（報道の自由強化）

## 🎬 デモシナリオ

### シナリオ1: 海外視察費の開示請求
1. **入力**: 「市長の海外視察費用が知りたい。何百万円も使って成果が分からないのは許せない」
2. **怒りメーター**: 8/10
3. **条例マッチング**: 安城市情報公開条例第7条第4号
4. **必要文書**: 海外視察報告書、出張命令書、復命書、契約関係書類
5. **開示請求書生成**: AI自動生成
6. **経路案内**: 駅すぱあとAPIで安城市役所までのアクセス

1. **入力**: 不開示決定通知書の内容

3. **判例・開示例**: 名古屋市の開示事例を参照
4. **審査請求書生成**: 90日以内の期限内で

## 🎯 講評時の想定質問への回答

### Q1: 弁護士法72条に抵触しないか？
A: AIは「法的助言」ではなく「情報提供・書式作成支援」に限定。最終判断は市民が行う。Legal AI株式会社の本人訴訟支援サービス（無料提供）が同じアプローチで弁護士法72条をクリアしている。

### Q2: なぜ市民の「怒り」にフォーカスするのか？
A: 日本の情報公開請求制度の**心理的障壁**を解消するため。技術的な仕組みは整っているが、市民の「怖い・わからない・無駄だ」という感情が利用を阻いでいる。

### Q3: 既存の弁護士向けAI（AILEX等）との違い
A: 既存は**弁護士向け**で月額サブスク。Civic Lensは**市民向け**で完全無料。Legal AIの本人訴訟支援と同じ思想で情報公開に特化。

### Q4: 社会的インパクトは？
A: 年間30万件以上の情報公開請求のうち、市民の90%が挫折。1%でも改善すれば3,000件/年。報道の自由強化にも寄与。

### Q5: デモで見せられるものは？
A: 1. 怒り入力 → 条例マッチング → 請求書生成 → 経路案内（フルフロー）
   2. 不開示決定通知書 → 反論ロジック → 審査請求書
